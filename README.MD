 Campus Network Design and Implementation

 Project Overview

Designed and implemented a campus network using Cisco Packet Tracer with VLAN segmentation, Inter-VLAN Routing, OSPF, DHCP, NAT, and SSH.

Technologies Used

- Cisco Packet Tracer
- VLAN
- Inter-VLAN Routing
- OSPF
- DHCP
- NAT
- SSH
- Cisco Routers and Switches

 Key Implementations

- Designed a structured campus network topology.
- Configured VLANs for network segmentation.
- Implemented Inter-VLAN Routing for communication between VLANs.
- Configured OSPF for dynamic routing.
- Configured DHCP for automatic IP address assignment.
- Implemented NAT for network address translation.
- Configured SSH for secure device management.
- Tested connectivity between network devices and end hosts.

 Project Files

- `campus-network.pkt` – Cisco Packet Tracer network project.

 Project Outcome

Successfully designed and configured a campus network environment and tested routing, VLAN communication, DHCP, NAT, and secure device access.
